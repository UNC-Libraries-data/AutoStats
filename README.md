# AutoStats 3.0 is here!

[Click here to start using AutoStats.](https://unc-libraries-data.github.io/AutoStats/)<br>
*Instructions and documentation available in the Help tab.*

The latest version of AutoStats uses [shinylive](https://posit-dev.github.io/r-shinylive/), an R package that allows Shiny apps to run in your web browser without any need for a backend server. **This means you will have to wait a bit for the app to load, espeically if you are using it for the first time.**

There are a number of limitations to the type data that can be uploaded using AutoStats. Please see the [release notes] to learn more.

Because I have only tested this app with my own files, it is reccommended you check your records on LibInsight after they are uploaded to make sure everything is going through correctly. [Please submit any issues or reccommendations here.](https://github.com/UNC-Libraries-data/AutoStats/issues)
